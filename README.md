# Guitarnautics

The guitar drill videos in course order, with a count of how many times each has been watched.

- Open the site on your phone and **Add to Home Screen**: it runs full-screen like an app.
- Tap a video to play it; a watch counts once 90% of it has played. Counts are stored on the phone.
- Built from `tools/drillvideo/app_build.py` in the Guitar Cards repo, which compresses the renders into `videos/`
  and writes `catalogue.json`.
